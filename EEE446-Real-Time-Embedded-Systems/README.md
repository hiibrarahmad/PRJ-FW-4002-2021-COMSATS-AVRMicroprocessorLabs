# EEE446 — Real-Time Embedded Systems

Four Arduino-IDE exercises interfacing 7-segment displays and character LCDs with an Arduino Uno:

| Task | What it does |
|---|---|
| [`Task1-7Segment-0-to-9/`](Task1-7Segment-0-to-9) | Single 7-segment display counts 0–9. |
| [`Task2-7Segment-000-to-999/`](Task2-7Segment-000-to-999) | Three multiplexed 7-segment digits (shift-register driven) count 000–999. |
| [`Task3-LCD-Hello-World-Counter/`](Task3-LCD-Hello-World-Counter) | 16x2 LCD prints "Hello World" and a running counter. |
| [`Task4-LCD-Name-RegNumber/`](Task4-LCD-Name-RegNumber) | 16x2 LCD prints name and registration number. |

Each task folder has its own real circuit diagram in `assets/`.
