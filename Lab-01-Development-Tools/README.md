# Lab 1 — Introduction to Development Tools and Lab Softwares

First lab of the *Microprocessor Systems and Interfacing* course. Objectives: get comfortable with Arduino IDE, Atmel Studio / AVR Studio, and Proteus for the ATmega328P.

**Task 2** (`main.c`): direct-register LED blink — sets all of `PORTB` as output, toggles bit 5 high/low with a 100ms delay in between. No Arduino framework, straight `avr/io.h` register access.
